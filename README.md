# Role_exporter_node
Structure du rôle
La structure d'un rôle Ansible pour Node Exporter peut ressembler à ceci :
roles/
├── Role/
│   ├── tasks/
│   │   ├── main.yml
│   ├── handlers/
│   │   ├── main.yml
│   ├── vars/
│   │   ├── main.yml
│   ├── defaults/
│   │   ├── main.yml
│   ├── meta/
│   │   ├── main.yml
